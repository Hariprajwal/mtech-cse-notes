7. COURSE OUTCOMES
==================================================

CO1: Analyse the need of parallel computing with the
structure of parallel computers.

CO2: Summarize the salient features of different multi-core
architectures to exploit parallelism using OpenMP.

CO3: Demonstrate how to apply point-to-point and collective
communication primitives in writing MPI programs.

CO4: Design and implement parallel programs in modern
environments using OpenCL.

CO5: Analyze and design parallel programs to enhance
machine performance in parallel hardware environment
using CUDA.

CO6: Apply the principles learnt in developing the design
of Interconnection network for a parallel computer,
OpenMP programming and association with applications
of parallel processing.
